# Telegram Group Chat Assistant Bot

AI-ассистент для групповых чатов в Telegram. Помогает участникам обсуждений, отвечает на вопросы и поддерживает контекст диалога.

---

##  Возможности

- Формирование контекста для LLM из истории сообщений чата
- Ответы в групповых чатах по упоминанию (`@bot_name`)

---

##  Как работает

Бот:

- сохраняет последние сообщения каждого чата в памяти
- использует эту историю как контекст для модели
- отправляет запрос в LLM только при упоминании бота
- возвращает сгенерированный ответ в чат

## Запуск

- для работы в групповом чате нужно отключить у бота Privacy Mode.
